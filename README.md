# MNRE social media dashboard

Week-over-week view (Monday to Sunday) of the MNRE accounts on Instagram, Facebook, YouTube and X.

- `index.html` is the dashboard: a single static page with the data embedded.
- `weekly.json` and `daily.json` hold the numbers behind it.

First snapshot: weeks 2-8 Nov and 9-15 Nov 2026, pulled on 19 Nov 2026.

Not included yet: LinkedIn, paid vs organic split, comments and sentiment. Meta dates are in Pacific Time.
