# MNRE social media dashboard

Week-over-week view (Monday to Sunday) of the MNRE accounts on Instagram, Facebook, YouTube and X.

- `index.html` is the public dashboard. It is a single static page with the data embedded; open it in a browser or serve it with GitHub Pages.
- `data/weekly.json` and `data/daily.json` hold the numbers behind it.
- `dashboard-source.html` is the original page written for Claude's dashboard runtime, kept for reference.

First snapshot: weeks 2-8 Nov and 9-15 Nov 2026, pulled on 19 Nov 2026.

Meta dates are in Pacific Time.
